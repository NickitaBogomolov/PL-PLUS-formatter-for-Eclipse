# PL+ Formatter for Eclipse

Плагин для Eclipse, который форматирует исходный код на языке PL/SQL (PL+) и автоматически приводит файлы `.plp` к единому стилю оформления.

Плагин поддерживает:
- ручное форматирование по команде
- автоформатирование при сохранении файла `*.plp`
- настройку глубины отступов
- работу с файлами `.plp`, `.plsql`, `.pls`, `.sql`

## Что умеет плагин
- форматирует ключевые конструкции PL+
- нормализует пробелы вокруг операторов и разделителей
- выравнивает отступы по блокам `BEGIN...END`, `IF...THEN`, `LOOP`, `CASE`
- поддерживает быстрый вызов команды форматирования из контекстного меню
- может форматировать файл автоматически при сохранении

## Требования
Для сборки и запуска плагина потребуется:
- Eclipse IDE for Java Developers
- Eclipse Plug-in Development Tools (PDE)
- Java 17+
- Eclipse 2022-09 или новее

## Установка в Eclipse
### Способ 1. Установка из собранного архива
1. Скомпилируйте проект в Eclipse через `Export -> Plug-in Development -> Deployable plug-ins and fragments`.
2. Получите архив с плагином или папку с плагином.
3. В Eclipse откройте:
   - `Help -> Install New Software`
4. Нажмите `Add...`.
5. Выберите `Archive...` и укажите собранный архив.
6. Выберите плагин и установите его.
7. Перезапустите Eclipse.

### Способ 2. Установка из исходников
1. Откройте Eclipse.
2. Импортируйте проект как:
   - `File -> Import -> Existing Projects into Workspace`
3. Выберите папку с проектом `PL-PLUS-formatter-for-Eclipse`.
4. Дождитесь сборки проекта.
5. Запустите Eclipse Runtime для проверки.

## Установка из открытого репозитория GitHub

Поскольку проект находится в открытом репозитории на GitHub, у пользователя есть два стандартных варианта установки в Eclipse:

### Вариант 1: Склонировать репозиторий и открыть в Eclipse
1. Откройте GitHub и перейдите в репозиторий проекта.
2. Нажмите `Code -> Download ZIP` или выполните:
   ```bash
   git clone https://github.com/<username>/<repository>.git
   ```
3. В Eclipse выберите:
   - `File -> Import -> Existing Projects into Workspace`
4. Укажите папку с клоном проекта.
5. Дождитесь загрузки проекта.
6. Для проверки запустите Eclipse Runtime (`Run -> Run As -> Eclipse Application`).

### Вариант 2: Установить плагин из ZIP-архива GitHub
1. На GitHub скачайте архив релиза или ZIP проекта.
2. В Eclipse откройте:
   - `Help -> Install New Software`
3. Нажмите `Add...`.
4. Выберите `Archive...`.
5. Укажите скачанный архив `.zip`.
6. Выберите плагин `PL+ Formatter`.
7. Нажмите `Next`, затем `Install`.
8. Перезапустите Eclipse.

### Важно для открытого GitHub-репозитория
- Eclipse не устанавливает плагины напрямую из GitHub-URL без архива или update-site.
- Для обычных пользователей самый простой путь — скачать ZIP из репозитория и установить через `Help -> Install New Software -> Add -> Archive`.
- Для разработчиков — клонировать репозиторий и открыть проект в Eclipse как Plug-in Project.

## Установка в Eclipse (короткая инструкция)
1. Скачайте ZIP с репозитория GitHub или выполните `git clone`.
2. Откройте проект в Eclipse.
3. Убедитесь, что установлен `Eclipse Plug-in Development`.
4. Соберите плагин через:
   - `File -> Export -> Plug-in Development -> Deployable plug-ins and fragments`
5. Установите полученный архив через `Help -> Install New Software`.
6. Перезапустите Eclipse.

## Использование
После установки плагина:
1. Откройте файл `*.plp` (или `*.plsql`, `*.pls`, `*.sql`).
2. В контекстном меню файла выберите:
   - `Format PL+ code`
3. Либо откройте команду через меню/поиск команд Eclipse.

## Автоформатирование при сохранении
Чтобы форматирование происходило автоматически:
1. Откройте:
   - `Window -> Preferences`
2. Перейдите в раздел:
   - `PL+ Formatter`
3. Включите параметр:
   - `Форматировать файл при сохранении (*.plp)`
4. Сохраните файл — содержимое будет отформатировано автоматически.

## Настройки
В окне настроек доступны:
- включение/выключение автоформатирования
- размер отступа

Параметры хранятся в preference store Eclipse и доступны при каждой загрузке среды.

## Сборка проекта
Для сборки проекта в Eclipse:
1. Откройте проект в Eclipse PDE.
2. Убедитесь, что все зависимости подключены через `MANIFEST.MF`.
3. Выполните сборку проекта.
4. Для распространения используйте экспорт плагина как `Deployable plug-ins and fragments`.

## Пример форматирования
### До
```plsql
BEGIN
IF x=1 THEN
SELECT * FROM t WHERE a=1;
END IF;
END;
```

### После
```plsql
BEGIN
  IF x = 1 THEN
    SELECT *
      FROM t
     WHERE a = 1;
  END IF;
END;
```
