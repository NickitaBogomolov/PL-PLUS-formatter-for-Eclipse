# PL+ Formatter for Eclipse

Плагин для форматирования кода PL/SQL (PL+) в Eclipse. Поддерживает файлы `.plp`, а также общие расширения PL/SQL (`.plsql`, `.pls`, `.sql`).

Цель плагина — привести код к единообразному стилю, упростить чтение и автоматизировать форматирование при сохранении файла.

## Возможности

- форматирование кода PL+: отступы по блокам (`begin/end`, `if`, `loop`, `case`, `exception`, пакеты и процедуры), пробелы вокруг операторов, удаление лишних пробелов и пустых строк
- ручная команда форматирования (`Ctrl+Shift+F`)
- автоматическое форматирование при сохранении (опционально)
- настройка размера отступа, регистра ключевых слов (строчные / ПРОПИСНЫЕ / не изменять) и числа пустых строк подряд
- поддержка стандартных расширений PL/SQL

Форматтер не изменяет строковые литералы, комментарии и PL+-имена в квадратных скобках (`::[CLASS].[ATTR]`) и сохраняет разбиение кода на строки.

## Требования

- Eclipse IDE для Java Developers
- Eclipse Plug-in Development Tools (PDE)
- Java 17+
- Eclipse 2022-09 или новее

## Установка из открытого репозитория GitHub

ZIP-архив репозитория содержит исходный код, а не p2-репозиторий, поэтому установить его напрямую через `Help -> Install New Software -> Archive...` нельзя. Сначала соберите jar-файл плагина, затем положите его в каталог `dropins` Eclipse.

### Шаг 1. Скачайте архив репозитория

1. Откройте репозиторий на GitHub.
2. Нажмите кнопку `Code`.
3. Выберите `Download ZIP`.
4. Распакуйте ZIP-файл на компьютере.

### Шаг 2. Соберите плагин

Вариант А — в Eclipse с установленным PDE:

1. `File -> Import -> Existing Projects into Workspace`, укажите распакованную папку.
2. `File -> Export -> Plug-in Development -> Deployable plug-ins and fragments`.
3. Отметьте `plplus.formatter`, укажите каталог назначения и нажмите `Finish`.
4. В каталоге назначения появится `plugins/plplus.formatter_1.0.0.<дата>.jar`.

Вариант Б — через Maven (нужны Maven 3.9+ и JDK 17+):

```bash
mvn clean verify
```

Результат — `target/plplus.formatter-1.0.0-SNAPSHOT.jar`.

### Шаг 3. Установите плагин в Eclipse

1. Скопируйте собранный jar в каталог `dropins` установленного Eclipse (рядом с `eclipse.exe`).
2. Перезапустите Eclipse.

### Шаг 4. Включите автоформатирование

1. Откройте:
   `Window -> Preferences`
2. Перейдите в раздел:
   `PL+ Formatter`
3. Включите опцию:
   `Форматировать при сохранении в редакторе PL+`
4. Сохраните настройки.

## Использование

После установки плагина:

1. Откройте файл `.plp` в Eclipse (`.plp`, `.pls`, `.plsql` открываются в `PL+ Source Editor` автоматически, `.sql` — через `Open With -> PL+ Source Editor`).
2. Используйте команду форматирования вручную или просто сохраните файл.
3. Если опция автоформатирования включена, форматирование будет применяться автоматически при каждом сохранении.

### Команда форматирования

В контекстном меню редактора можно вызвать команду:

- `Format PL+ Code` (`Ctrl+Shift+F`)

Форматирование отменяется одним `Ctrl+Z`.

### Настройки

`Window -> Preferences -> PL+ Formatter`:

- форматировать при сохранении в редакторе PL+ (по умолчанию выключено)
- размер отступа (по умолчанию 2 пробела)
- регистр ключевых слов: строчные (`begin`, `end`; по умолчанию) / ПРОПИСНЫЕ (`BEGIN`, `END`) / не изменять. Меняется только регистр ключевых слов, имена переменных, таблиц и PL+-атрибутов не затрагиваются
- максимум пустых строк подряд (по умолчанию 1)

## Поддерживаемые расширения

- `.plp`
- `.plsql`
- `.pls`
- `.sql` (через `Open With`)

## Сборка из исходников

Если вы хотите открыть проект в Eclipse как плагин и собрать его самостоятельно:

1. Скачайте репозиторий с GitHub или клонируйте его:
   ```bash
   git clone https://github.com/<username>/<repository>.git
   ```
2. В Eclipse выберите:
   `File -> Import -> Existing Projects into Workspace`
3. Укажите папку проекта.
4. Убедитесь, что установлен `Eclipse Plug-in Development`.
5. Запустите проект как Eclipse Application для проверки.
6. При необходимости экспортируйте плагин через:
   `File -> Export -> Plug-in Development -> Deployable plug-ins and fragments`

## Пример форматирования

### До

```plsql
BEGIN
IF x=1 THEN
SELECT * FROM t WHERE a=1;
END IF;
END;
```

### После

```plsql
begin
  if x = 1 then
    select * from t where a = 1;
  end if;
end;
```

## Примечание

Это базовая реализация форматтера для PL/SQL (PL+), рассчитанная на простую и понятную работу в Eclipse. Для более сложного и строго структурированного форматирования можно расширить логику парсинга и правил форматирования по конкретному стандарту команды или проекта.
